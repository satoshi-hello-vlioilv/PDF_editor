# UI/UX 設計見直し記録

`CLAUDE.md` の「UI/UX 修正のルール」に沿って実施した評価の記録です。
各案は実アプリに CSS/JS を注入したモックアップとして作成し、1440×900（＋900×700）のキャプチャで評価しました。

評価基準（100点）: 使いやすさ20 / わかりやすさ15 / 直感性15 / 汎用性15 / 視覚表現15 / 階層構造・領域確保20

---

## v1.3.0（2026-10-12）全面見直し

### 現状（v1.2.0）の課題

- ツールバー2段に約40個のボタンが常時並び、多くがアイコンのみで意味がわかりにくい（同じアイコンの重複: 回転/反転/フィット）。
- 選択していないと使えない操作も常時表示（無効状態）され、ノイズになっている。
- 左サイドバー（256px）が「ファイル一覧」と「出力設定」をタブで切替えており、常時領域を占有。ファイル一覧は2〜3件でも縦に大きく空く。
- ページカードの既定サイズが大きく（1440px幅で4列程度）、一覧性が低い。
- ビューワーのヘッダーに20個以上のアイコンが一列に並び、ページ送りは画面端の薄い矢印のみ。

### 実装後の確認

- 実装版を同じ手順でキャプチャし、未選択／選択／メニュー展開／出力設定ドロワー／保存ダイアログ／ビューワー（一覧・画像調整）／リスト表示／ダーク／900px幅を確認。
- Playwright による操作テスト 36項目（チップでのファイル選択、回転・反転・複製・削除・元に戻す、メニュー開閉とEsc、出力設定バッジ、保存ダイアログ、ショートカット、サイズスライダー、ビューワーのページ送り・一覧ジャンプ・その他メニュー・画像調整、リスト表示、チップからのファイル削除）がすべて成功し、ページエラーなし。
